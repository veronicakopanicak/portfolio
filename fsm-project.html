THE CIRCUIT IN PRACTICE

I designed and implemented a sequential digital logic circuit that cycles through the nine-digit sequence 400556686 on a seven-segment display.

The circuit uses a finite state machine (FSM) constructed from six J-K flip-flops. Four flip-flops represent the displayed digit in binary-coded decimal (BCD), while two additional flip-flops distinguish repeated digits that require different state transitions.

A BCD-to-seven-segment decoder converts the binary output into the corresponding numerical digit. The project involved developing excitation tables, simplifying Boolean expressions using Karnaugh maps, verifying circuit behaviour in NI Multisim, and implementing the design on a physical breadboard.

Finite state machine design

The circuit was designed as a finite state machine (FSM) using six J-K flip-flops to control the sequence of digits displayed on a seven-segment display.

Four flip-flops (Q1–Q4) represent the current digit in binary-coded decimal (BCD), while two additional flip-flops (C5 and C6) distinguish between repeated digits in the sequence.

Since the sequence 400556686 contains repeated digits, the same BCD output can require different transitions depending on its position in the sequence. The two additional flip-flops provide the information needed to distinguish these states and ensure the circuit advances through the correct sequence with each clock pulse.

Boolean simplification

I then used six-variable Karnaugh maps to simplify the Boolean expressions needed to implement the circuit.

Key design decisions included:

  • Sum-of-products (SOP) simplification: Selected because the Karnaugh maps contained fewer 1s than 0s.
  • Don’t-care conditions: Used to simplify Boolean expressions and reduce the required logic.
  • Hardware optimization: Used two additional flip-flops instead of three to reduce the number of components while maintaining the correct sequence.

Same digit. Different state.

Handling repeated states

THE CHALLENGE

Identical BCD outputs can require different next states.

THE SOLUTION

Repeated digits in the sequence could require different next states despite producing the same BCD output. I incorporated two additional flip-flops to distinguish these positions, allowing the finite state machine to select the correct transition.

Minimizing hardware complexity

THE CHALLENGE

Reduce the number of flip-flops without losing the required state transitions.

THE SOLUTION

One design challenge was reducing the number of flip-flops required to distinguish repeated digits in the sequence. I chose to use two additional flip-flops instead of three, reducing the number of components required. This decision introduced more complex Boolean expressions but allowed the circuit to achieve the required state transitions with fewer flip-flops.

03 // INPUT COMPATIBILITYCONCEPTUAL INPUT INVERSION

Simulation and hardware compatibility

THE CHALLENGE

The simulated and physical flip-flops use different K-input conventions.

THE SOLUTION

The simulated J-K flip-flops and the physical J-K components used different K-input conventions. I accounted for this difference using inverters in the Multisim circuit, while the physical implementation followed the active-low K-input configuration.
