01 / PROJECT DETAILS

Project overview

I designed and implemented a sequential digital logic circuit that cycles through a predefined nine-digit sequence on a 7-segment display.

The system uses a finite state machine (FSM) built from J-K flip-flops to control transitions between states. A BCD-to-7-segment decoder converts the four-bit binary output into numerical digits. The project covered analytical logic design, Boolean simplification, circuit simulation, and physical hardware implementation.

02 / PROJECT DETAILS

Design and methodology

Finite state machine design

The circuit uses six J-K flip-flops:

  • Four flip-flops (Q1–Q4) hold the BCD-encoded digit shown on the display.
  • Two additional flip-flops (C5 and C6) distinguish repeated digits within the sequence.

The counter flip-flops are necessary because identical digits appear at several positions and need different next states.

Excitation table and Boolean simplification

I built a complete excitation table to find the J and active-low K inputs each flip-flop needs for every transition. Six-variable Karnaugh maps then simplified the Boolean expression for each input, and the results were implemented directly with AND and OR gates.

  • Sum-of-products (SOP) simplification, since the maps had far fewer 1s than 0s.
  • Don’t-care conditions to reduce the logic.
  • Two counter flip-flops instead of three, to reduce hardware.
03 / PROJECT DETAILS

Circuit simulation

I modelled and simulated the circuit in NI Multisim to verify it before building it. The simulated circuit included:

  • 6 J-K flip-flops, 7 AND gates, and 5 OR gates
  • 3 NOT gates for simulation-specific signal inversion
  • A BCD-to-7-segment decoder, a 7-segment display, and a clock signal

The NOT gates accommodate the difference between the simulator’s J-K flip-flops and the active-low K inputs of the physical components.

04 / PROJECT DETAILS

Simulation results and verification

I examined timing diagrams generated in Multisim, reading the four BCD flip-flop outputs at successive rising clock edges. The initial state was set to decimal 4 (BCD 0100).

The timing diagrams confirmed that the circuit moved through all nine states in the correct order and then repeated the sequence.

05 / PROJECT DETAILS

Physical implementation

After simulation, I assembled the circuit on a breadboard using digital logic components: J-!K flip-flops, logic gates, and a BCD-to-7-segment display system. The build followed the simplified Boolean expressions from the analytical design.

Because the physical flip-flops have active-low K inputs, the build does not need the extra inverters used in the simulation.

06 / PROJECT DETAILS

Engineering challenges and design decisions

Handling repeated states

Identical BCD outputs could require different next states, so I added two flip-flops to track the position in the sequence.

Minimizing hardware complexity

I used two counter flip-flops instead of three. This reduced the hardware needed, at the cost of more complex Boolean expressions.

Simulation and hardware compatibility

Multisim used standard J-K flip-flops while the physical circuit used J-!K flip-flops, so I added inverters to the simulation to account for the difference.

07 / PROJECT DETAILS

Key takeaways

The Multisim simulation demonstrated the intended nine-state sequence, with timing diagrams verifying the transitions. The project gave me practical experience in:

  • Sequential digital logic design and FSM implementation
  • Boolean simplification and logic optimization
  • Circuit modelling and simulation
  • Digital hardware implementation and simulation-based verification
